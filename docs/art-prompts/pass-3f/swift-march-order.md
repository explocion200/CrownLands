# Swift March Order

Create a weathered urgent military dispatch: folded parchment order secured to a worn brown leather courier case, tied cord, rust-red wax seal, small dull-steel riding spur and stamped horse-head seal motif. Keep the bundle compact and travel-worn. Follow the Pass 3F shared specification. Avoid wings, speed lines, blue ribbons, glowing effects, readable writing, and anachronistic postal imagery.
