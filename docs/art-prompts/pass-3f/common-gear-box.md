# Common Gear Box

Create a stout Crownlands royal quartermaster equipment chest: scratched oak planks, hand-forged iron corner brackets and hinges, weighty practical front latch, a restrained burned crown-and-wall heraldic mark, and a small worn burgundy leather tab. Closed, centered, three-quarter view, readable as a working armory chest rather than a treasure chest. Allow enough lid and side profile for the runtime opening movement to feel physical. Follow the Pass 3F shared specification. Avoid jewels, blue lacquer, treasure, glow, runes, gold bands, and fantasy ornament.
