# Profile HUD Frame

- Function: compact ruler identity plaque framing the live kingdom flag and hero level.
- Canvas: 1419x1108 RGBA; runtime 256x200.
- Composition: broad low carved-oak plaque with restrained iron corner straps, a thin muted-brass inner lip, tiny burgundy cloth tab centered at top, and a large clean transparent opening aligned to the existing flag safe zone. Keep the lower-right edge clear for the level badge.
- Safe zones: transparent opening approximately x=19-81%, y=25-78%; outer frame within 3-97%; no ornament protruding below 95%.
- Materials/light: dark oak, hammered iron, tarnished brass, burgundy wool; near-front view, soft upper-left daylight.
- Readability: portrait/flag remains primary; frame is thin and practical.
- Negative: no fleur-de-lis, blue enamel, ornate scrollwork, dangling medallions, giant crown, jewels, glow, white fill, or painted background.
