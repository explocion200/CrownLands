# Gatehouse

- Exact target dimensions: 1254x1254 opaque PNG source, 512x512 optimized WebP runtime.
- Runtime display dimensions: square preview image in the Inner Castle tray.
- Aspect ratio: 1:1.
- Camera: consistent three-quarter defensive command space with gate and mechanism visible.
- Composition: heavy oak gate, portcullis, chains, guard room, alarm bell, wall tools, stacked supplies.
- Lighting: daylight from gate opening plus restrained torch/candle light.
- Materials: thick warm gray stone, iron straps, oak beams, rope, leather, dull steel.
- Humans/props: guards, keys, polearms, ladder, repair tools, defensive stores.
- UI safe zones: gate/portcullis remains the main silhouette and readable at small size.
- Heraldry: burgundy/faded-blue guard banners, worn and stitched.
- Negative instructions: no glowing force field, shield-shaped building, impossible fantasy gate, modern insignia, firearms, or text.
- Function: communicate castle security, wall control, and defense command.
- Officer visual inheritance: Defensive Commander should inherit stone/iron surroundings, gate keys, wall tools, guard insignia, helmets, polearms, and command readiness.
