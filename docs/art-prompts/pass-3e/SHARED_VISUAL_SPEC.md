# Crownlands Pass 3E Shared Visual Specification

## Scope

Pass 3E replaces the four officer portraits and all 32 Common Gear item masters. It does not change gear IDs, names, statistics, bonuses, upgrade costs, equipment behavior, inventory behavior, Firebase data, or gameplay rules.

## Canonical Dimensions

- Officer source master: 1086 x 1448 opaque RGB PNG (3:4 portrait).
- Officer optimized runtime image: 768 x 1024 opaque WebP.
- Common Gear source master: 1254 x 1254 RGBA PNG with a transparent background.
- Common Gear optimized runtime image: 192 x 192 RGBA WebP on an intentionally preserved square canvas.
- Item silhouettes should occupy roughly 68-84% of the square safe area without touching the canvas edge.

## Shared Portrait Language

- All four officers are unmistakably adult men.
- Grounded Crownlands late-medieval material culture, circa 1350-1500 Western/Central European frontier society.
- Full-body three-quarter portrait at human scale, eye level near the upper third, feet visible, practical stance.
- Painterly naturalism matching the approved Inner Castle scenes, with restrained detail and no photographic gloss.
- Soft daylight supported by believable hearth or window light. No magical rim light or colored glow.
- Dressed fieldstone, dark oak, limewashed plaster, worn leather, dull iron, quality wool, linen, and restrained brass.
- Burgundy is the primary royal cloth accent. Faded blue, moss, ochre, rust, charcoal, and parchment support it.
- Each background is the officer's approved Inner Castle workplace and remains subordinate to the man.
- Faces must be distinct in age, structure, hair, beard, complexion, expression, and posture.

## Shared Gear Language

- Every object is an isolated, historically plausible late-medieval equipment or administrative item.
- Painterly game-item rendering matches the portraits and Inner Castle materials.
- Three-quarter product view, centered, readable at 32-96 px, with generous transparent padding.
- Dull iron, weathered oak, oxblood/burgundy wool, parchment, dark leather, linen, muted brass, and faded dye.
- Wear is functional: rubbed edges, repaired seams, tool marks, soot, tarnish, and faded paint.
- No labels, text, frames, pedestals, rarity glow, floating particles, cast shadows, or rectangular backplates.
- Treasury's weapon-slot object is a royal ledger with wax seals and a counting tool. It is never a weapon.

## Negative Rules

No women or ambiguous gender presentation for the four officers; no modern hairstyles; no modern medals; no modern insignia; no telescopes; no firearms; no fantasy plate; no giant pauldrons; no excessive gold; no neon; no blue or purple magic; no glowing weapons; no floating objects; no superhero anatomy; no pristine costume styling; no text or watermark.
