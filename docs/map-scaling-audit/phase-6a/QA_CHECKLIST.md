Approval must explicitly answer:

- Does this generated environment look like the same Crownlands world as the current approved cities, Strongholds, Citadel, and Camps?
- Does the map feel distinctive without being overcrowded?
- Do all four edges visually feel closed except for their single road passage?

If any answer is no, Phase 6 must not scale to the complete asset library.
