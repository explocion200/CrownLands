# Phase 6C Asset Expansion Decision

## Decision

The current 86-asset library is not sufficient for 1,000 player maps without recognizable macro repetition and cannot reasonably scale toward 10,000 maps unchanged.

This is not an art-style rejection. The approved Phase 6A simplicity, readability, density, edge behavior, and four regional identities remain locked. The deficiency is the number of large-scale compositions available to the approved style.

## Minimum evidence-based additions

| Family | Current limiting behavior | Minimum addition |
| --- | --- | ---: |
| Foundations | One plate per theme; only horizontal flip varies it | +8 (two per theme) |
| Edge segments | One complete eight-piece frame per theme | +16 (four swappable segments per theme) |
| Internal roads | One fixed cross geometry for every map | +8 (two internal modules per theme) |
| Interior accents | 1,000 unique placement plans at approved density | +0 |

The smallest recommended library is therefore 118 assets, not 311.

Three foundation plates per theme provide six approved presentations when the existing horizontal transform is valid. Four alternate edge segments per theme provide combinatorial silhouettes without widening the barrier or adding clutter. Two internal road modules per theme provide deterministic bends/junction choices while retaining exactly one centered exit per cardinal side.

No new art was created in Phase 6C. These additions require approval slices and a repeat of the same large-sample gate.
