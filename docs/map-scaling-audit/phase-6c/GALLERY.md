# Phase 6C Gallery

Open `benchmark-results/map/phase-6c/gallery/index.html` for the complete development QA gallery.

It contains:

- 25 deterministic random maps
- the same 25 maps with all 40 city positions
- 25 highest-similarity pairs
- 16 representative maps per directional family
- 25-map and 100-map sequential runs
- complete Layer 1 and Layer 2
- all four directional transition families
- repeated-foundation comparisons
- repeated-edge comparisons
- repeated-road comparisons

The gallery contains no baked Gates, cities, Camps, Strongholds, Citadel, arrows, labels, or UI. City dots appear only in the dedicated QA overlay sheet.
