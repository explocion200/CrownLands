# Phase 6D Asset Provenance

The eight new foundation sources were created with the built-in OpenAI ImageGen workflow, using the locked Phase 6B foundation and approved Phase 6A directional master as visual references. The source files are preserved under `tools/map-scaling-phase-6d/source/foundations/` before deterministic normalization and theme harmonization.

The prompt contract for every v2 plate was: create a production Crownlands macro-variation foundation in the exact approved painterly medieval style, camera, lighting, and directional theme; use an edge-to-edge 4:3 object-free quiet terrain plate with varied broad color and ground texture; include no road, path, barrier, mountain, rock, tree, forest, pond, building, city, gate, UI, border, or margin. Each v3 prompt used the locked base and v2 result as references and required a clearly different broad ground organization while preserving the same hard exclusions.

Generated source plates are development assets. The deterministic build blends them with the locked theme foundation, normalizes them to 1448×1086, and records the resulting asset hashes in `benchmark-results/map/phase-6d/asset-library/asset-manifest.json`.

The 16 edge alternatives are deterministic full-side extractions from approved directional artwork. The eight road modules are deterministic code-rendered route overlays using the locked road palette, width, sockets, and grounded medieval presentation.
