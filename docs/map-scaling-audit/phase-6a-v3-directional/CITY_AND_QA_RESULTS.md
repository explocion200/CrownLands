# Directional city and visual QA

Every directional sample contains exactly 40 deterministic city positions and two to four starting candidates. Existing 112-pixel separation, road-corridor exclusion, Gate/Arrow transition clearance, terrain blocker clearance, and edge clearance remain unchanged.

Significant winter trees/rocks, dry ridges, West woodland, East palm clusters, and inward perimeter features are authoritative development blockers. Small scattered stones, grass variation, and field texture remain playable ground rather than impassable terrain.

Initial 40-city layouts were rejected during visual QA where a marker overlapped a significant feature. The final receipts use later deterministic salts without weakening any placement rule.

Each sample provides a clean map, all 40 markers, an HTML overlay using the unchanged current city asset, four edge close-ups, a North road close-up, boundary-contact proof, and HTML comparison overlays for the current Castle, Gold Camp, Training Stronghold, and Crown Citadel.
