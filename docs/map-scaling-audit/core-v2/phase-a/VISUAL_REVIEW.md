## Known limitations before the remaining 20 maps

- This is an offline art/package prototype; runtime integration and activation are intentionally absent.
- Tower and Fortress gameplay and final art do not exist. Only authoritative reservation geometry is modeled.
- The remaining special Core identities may need a very small handcrafted prop vocabulary. Any such props should be approved separately and must replace—not add to—the current four-accent decoration budget.
- City nameplates, selection rings, and live ownership colors are not simulated in this art board. The actual city footprint is tested; a browser-scale interaction pass should precede final approval of all 25 maps.
- The full 25-map climate matrix is specified but only the connected five-map center/southwest path is visually composed.

No correction is required to the five city-safe coordinate plans before visual review. If the art direction is approved, the next Core v2 phase should lock these five prototypes, create a tiny objective-specific prop rulebook, and compose the remaining 20 maps in review batches rather than all at once.
