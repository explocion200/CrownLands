# Crownlands Core v2 Phase ART-3

Phase ART-3 rebuilds only the five approved Phase B1 backgrounds against the authoritative ART-2 v2 final Core standard. It is a development-only art pass: no new Core coordinate, city, objective, topology, blocker, transition, adjacency, spawn, Firebase, or production runtime state is created or changed.

The rebuilt coordinates are `(-2,-2)`, `(-1,-2)`, `(-2,-1)`, `(-1,-1)`, and `(-1,0)`. Their capacities remain `55/55/55/55/60`. Aurum Keep remains at exact center `(724,543)`; the Camp and Tower coordinates remain `(700,535)`, `(742,526)`, `(706,556)`, and `(736,552)`.

The candidates use handcrafted Core terrain, thin wagon roads, occupied-ground integration, calm city pockets, and a narrow natural perimeter touching the image boundary. Runtime Camps and Aurum Keep are overlays; the Tower remains a QA reservation only.

The review package is under `benchmark-results/map/core-v2-phase-art-3/`. It contains five clean candidates, all requested prototype/final comparisons, live browser captures at three zoom levels, interaction captures, the Relic comparison, and the ten-map style board.

Nothing in this phase is production-published or deployed.
