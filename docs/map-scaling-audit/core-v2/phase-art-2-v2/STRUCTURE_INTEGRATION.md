# Structure-ground integration

ART-2 v2 uses natural occupation footprints rather than circular pads or gameplay markers.

- Crown Citadel: maintained compacted earth, worn ceremonial convergence, feeder lanes, and a gradual return to countryside.
- Ironwatch: stony compacted ground, wagon-turning wear, hardened approaches, and military erosion.
- Southwest Holding Tower: crossing tracks and worn strategic ground with no Tower art and no placeholder pad.
- Deed Camp: wagon wear, feeder lanes, fenced-land transitions, and small settlement traffic.
- West Support: no objective footprint.

The runtime objective artwork is composited only in QA. The clean candidate backgrounds contain no Crown Citadel, Stronghold, Camp, Tower, Gate, arrow, city, label, banner, troop text, selection ring, action wheel, or route.
