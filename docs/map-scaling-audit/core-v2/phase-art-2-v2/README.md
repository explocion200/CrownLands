# Core v2 Phase ART-2 v2

ART-2 v2 is the approved, authoritative final art standard for all 25 permanent Core maps. This development checkpoint contains an art-quality revision of the same five Phase A backgrounds, preserves the approved Phase A geometry, and carries ART-1's visual principles into the final production-quality bar.

The revision adds Core-specific environmental authorship: narrower medieval wagon roads, occupied structure ground, deliberate geography, and richer detail placed between city-safe pockets. No new Core coordinate was generated. No runtime objective, city, Gate, arrow, label, route, or UI object is baked into a background.

## Scope

| Map | Coordinate | Capacity | Art result |
| --- | ---: | ---: | --- |
| Crown Citadel | (0,0) | 60 | Royal countryside, maintained approaches, occupied center |
| Ironwatch | (0,1) | 60 | Defensive ridges and compacted military ground |
| Southwest Holding Tower | (-1,1) | 55 | Worn strategic crossing; reservation only |
| Deed Camp | (-2,1) | 60 | Organic subordinate settlement and wagon traffic |
| West Support | (-2,0) | 70 | Cleanest map; subtle handcrafted agriculture and drainage |

The five ART-2 candidates remain intact beside the v2 candidates for direct comparison. The Phase A and Phase B1 prototype packages remain unchanged.

Only these five Phase A backgrounds currently meet the final standard. The five B1 backgrounds remain unchanged and will be rebuilt as ART-3 after this checkpoint. No new Core coordinate may be generated until all ten existing prototypes share the final visual standard.
