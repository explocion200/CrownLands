## Rebuild boundary

Future work should replace only the visual background/composition while preserving the approved coordinates, city counts, city spacing, city IDs, objective coordinates, topology, road sockets, runtime behavior, and production safety contracts. ART-1 performs none of that future work.

## Byte-preservation evidence

The ART-1 validator pins SHA-256 hashes for each existing `map.webp` and fails if any prototype background changes. It also requires exactly five Phase A and five Phase B1 prototype directories, proving that no additional Core map was generated.
