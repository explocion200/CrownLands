# ART-4 image-generation record

The built-in raster image-generation workflow edited five development geometry drafts. Each draft was first generated from the authoritative Core specification, blocker plan, road topology, and deterministic city plan. The edit target fixed the four cardinal sockets and internal road layout; prompts changed only the visual treatment.

Common prompt locks:

- final 1448×1086 Crownlands Core background;
- elevated painterly late-medieval terrain matching ART-2 v2 and ART-3;
- thin irregular wagon roads with ruts, hoof wear, muted soil, and soft reclaimed edges;
- narrow natural perimeter touching the literal image boundary;
- no cities, runtime objectives, Gates, arrows, labels, banners, routes, selection UI, text, or watermark;
- occupied objective ground without circles, pads, foundations, plazas, or gameplay markings;
- calm negative-space pockets for the authoritative city plan;
- no change to road geometry or edge sockets.

Map prompts added only the approved North Support, settled Deed frontier, edge-mining Gold territory, Greybanner mustering ground, and future Tower-reservation narratives. Source generation copies remain in the built-in image-generation output directory; accepted project copies are under `benchmark-results/map/core-v2-phase-art-4/candidates/`.
