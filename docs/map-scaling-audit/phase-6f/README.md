# Phase 6F — Road Geometry Decoupling

Phase 6F passes the development-only 10,000-map scale gate. It keeps the approved 118-asset library unchanged and separates the nine approved road shapes from the four regional visual treatments. Every geometry can now render in North, East, South, and West without duplicating the geometry definition.

The correction reduces the baseline-road share from 32.93% to 11.35%, reduces similarity pairs by roughly half in every measured band, preserves exactly 40 cities and four starting candidates on every map, and adds immutable published-package edge contracts. No terrain, foundation, perimeter, road, or accent asset was added.

Phase 7 production-integration planning may begin only after this checkpoint is reviewed. Phase 6F does not authorize activation, publication, deployment, or production data changes.
