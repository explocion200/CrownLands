# Corrected Phase 6A art direction

Phase 6A v2 supersedes the rejected first slice. Generation references only the current approved Crownlands city, Camp, Stronghold, and Crown Citadel assets. Older regional maps are deliberately excluded from the reference set.

The corrected composition is predominantly warm, open ground with restrained farmland, low rocks, and two small interior woodland groups. A narrow mixed rock/tree barrier stays close to the perimeter. Exactly one centered road passes through that barrier on each cardinal side.

The map contains no baked city, Camp, Stronghold, Citadel, Gate, arrow, objective, banner, label, or UI. OPEN/GATED state remains a runtime overlay over the same baked road opening.

The built-in ImageGen source arrived at 1449x1085 and was mechanically normalized to the required opaque 1448x1086 RGB approval format. Both files remain development-only; the normalized file is authoritative for the v2 QA receipt.

This is one approval slice, not full asset production and not a production-ready modular library.
