Gather the clan. Ready the assault.

The matching parchment window keeps all five activity categories above a compact rally selector and an open muster ledger. Target, map, creator, assembly city, troop totals, participant roles, readiness and arrival states stay available. Commands remain below the scrolling details.

Forming uses ochre, Launched burgundy, and Returning muted blue, with written labels throughout. Only the Rallies tab is in this draft. Existing permissions and manual launch rules are preserved; forming rallies have no automatic launch countdown.
