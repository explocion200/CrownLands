For this review

Eight medieval category badges, compact progress rows, claimable rewards first, and a fixed action area. The list and selected details scroll separately. Desktop and mobile landscape only.

All 40 objectives, targets, rewards, and requirement notes come from the current game. Production reward amounts become fixed on completion. Achievement progress and unclaimed rewards reset with the season; this draft adds no permanent honors or new rewards.

Review examples use synthetic data. No production game files or player data are changed.
