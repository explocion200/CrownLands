# Tiny City Estate review

This development-only page mounts the production renderer with three fixtures: six completed buildings and fourteen surveyed plots, all twenty completed buildings, and all twenty construction sites. It cannot spend resources, start construction, change saved progression or dispatch champions. Production excludes this page and its controls.

Run `node tools/map-benchmark/server.js --port=8816` from the feature checkout and open `http://127.0.0.1:8816/docs/visual-qa/inner-city-estate/index.html?scene=completed&revision=r5`. The bottom-right selector switches scenes. Pan, pinch/wheel zoom, Fit Estate, districts and the twenty-building directory use the production implementation. The logical map is 1448 × 1086, matching both the active topology's catalog and an actual illustrated regional asset. Full, Reduced and Off display the still estate; ambient motion is deferred.

`node tools/validate-inner-castle-browser.js` exercises all twenty selections at 1440×900, 844×390 and 568×320, twelve gear round trips, camera restoration, nonoverlapping 44px targets, mouse drag, wheel/touch pinch, keyboard camera controls, zoom bounds, animation preferences, background visibility, city/Profile entry and modal cleanup. It also checks centered freestanding art without soil overlays, Gatehouse target alignment, native sprite density and visible lazy detail tiles. Screenshots go to ignored `release-artifacts/inner-city-estate/`, including `fixture-completed.png`, `gatehouse-zoom-4x.png` and `city-zoom-4x.png`.

`node tools/validate-inner-city-estate.js` checks approved centers, finished reservations and contextual Gatehouse extraction coordinates, road-graph connectivity and entrance clearance, initial states, native image density, source hashes and bounded payloads. It reads the active catalog and an actual map WebP to verify dimensions. `node tools/validate-inner-castle.js` and `node tools/validate-common-gear.js` retain access, original preview artwork and authoritative gear checks. Production artifact validation verifies inclusion of all 27 estate images, bounded lazy close-ups and unchanged installation/login budgets.

Review the buildings on their integrated terrain ground in all three states, the Gatehouse foundation against both wall ends, common building scale and miniature silhouettes. There should be no repeated independent soil islands or spare work-yard clearings beside completed structures. At 4×, inspect roof timbers, masonry, outlines, terrain detail and tile seams. The world must rerasterize at the selected zoom rather than reuse an overview-resolution composited bitmap. Terrain, masonry and decorative cottages remain painted; site-state artwork changes independently within fixed reservations. Automated entrance checks apply to the layout graph; painted paths and junctions also require visual review.

The Master Specification and Art Bible record the requested corrections. Actual-device touch feel remains a useful manual review. Nothing in this page establishes a production deployment.
