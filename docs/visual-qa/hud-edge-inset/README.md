Branch: `codex/hud-left-edge-inset-draft`. Base: `9f08953e420c60af6a96bab36e32c2ee199c0f75`. Awaiting design approval; no production files or gameplay behavior changed.

Move the already-aligned player row and Gold closer to the screen edge. The desired outer inset equals the top buttons' existing gap: .28rem (4.48 CSS px at the current font size) above 760px viewport width, or .2rem (3.2px) at 760px and below. Preserve artwork, dimensions, vertical placement and all gaps within the block. The profile's compact combat timers move with their parent; other HUD controls stay put.

The existing layout runtime sets `.profile-stack` to `left:12px` inside `.top-hud`, which already has its own `max(.75rem,env(safe-area-inset-left))` inset. The player row and Gold each have a -7px margin, yielding the current 17px outer inset when the safe area is zero. The draft positions the stack relative to that containing header so the aligned row and Gold land at `safe-area-inset-left + icon gap`. A scoped CSS override stays effective when the layout runtime refreshes on resize. No production layout/configuration changes are included yet.
