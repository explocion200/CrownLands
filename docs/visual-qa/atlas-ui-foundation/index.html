Ink, paper, painted colour

Quiet parchment, fine rules, small cloth accents and clear illustrated silhouettes. The existing atlas remains the visual anchor.

Readable at a glance

Sentence-case text and clear numerals. A distinct marker and explicit labels carry ownership alongside colour. Primary commands keep one consistent shape.

Information within reach

City Details has a fixed command area and a scrolling ledger. Short landscape uses the available width without hiding the upgrade controls.
