# Camp artwork with transparent ground

Imagegen edited the approved v2 Gold, Warband, Relic and Deed scenes using the
owner's medieval atlas reference and the new map ground. The broad painted floor
was removed; buildings and equipment keep their established layout and colors.
Small contact shadows and olive grass immediately beneath objects remain.

`assets.json` records original and delivery hashes. Encode sources at 384 × 384,
WebP quality 86, alpha quality 100 and effort 6, preserving the entire transparent
canvas. The `replaces` path is the canonical server reference; `supersedes` is the
retired v2 browser file. Both project to the current content-addressed output.

Exact generation prompts, map integration and validation are documented in
[the ground cleanup notes](../../art-sources/clean-map-ground/README.md).
