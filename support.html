Crownlands support

Quick answers for common account, world, battle, installation, and reward questions.

Maintained by the Crownlands Development TeamUpdated August 16, 2026

Before reporting a problem

Refresh the page once, confirm the browser is online, and wait for the current kingdom to finish loading. If the game reports that a newer build is available, allow it to save and restart. For a multiplayer action, check the latest report or city panel after reconnecting because the server may have completed the action while the screen was stale.

When reporting an issue, include the approximate time, the visible error message, the affected city or target, the browser and device type, and the action taken immediately before the problem. Do not include passwords, authentication codes, private account tokens, or another person’s personal information.

Frequently asked questions

Why can’t I enter the kingdom?

Crownlands requires a valid Google sign-in and an available place in The Crown Marches. If the realm is full, the screen may show a queue. A second active session can also replace an older session for the same account.

Why did my troop or gold total change after reconnecting?

The server reconciles production, completed marches, captures, rewards, and other multiplayer changes. After the game has been closed for at least one minute, the next login shows the gold collected, troop production still remaining in cities you own, and any cities, Strongholds, or Citadel captured while you were away. Switching maps does not open this summary.

Why does a city show different information than my scout report?

A scout report is a snapshot. Troops, ownership, reinforcements, levels, or bonuses can change after the scout arrives. Check the report timestamp and scout again when accurate current intelligence matters.

Why was an army order rejected?

Common causes include changed ownership, insufficient troops, an invalid route, protection rules, a stale source city, or a server-side limit. Reopen the source and target panels to refresh their current state before trying a new order.

Why didn’t an advertisement give a reward?

A rewarded ad grants only after the advertising provider confirms completion and the server accepts the prepared reward intent. Closing early, blocking the ad, losing eligibility, receiving no fill, or a failed load grants nothing. Normal gameplay remains available without watching an ad.

Can I install Crownlands?

Supported browsers may offer an Install Crownlands button or an install icon. On iPhone and iPad, use Safari’s Share menu and choose Add to Home Screen. Installation keeps the web version easy to launch; it does not create a separate account.

How do I clear a broken cached build?

Reload while online first. If the problem remains, close every Crownlands tab and clear stored site data for playcrownlands.com in the browser’s privacy or site settings. Sign in again afterward so the current files and kingdom state can load.

Known limitations during active development

Crownlands is playable and remains under active development. Region capacity is configured per map and can change. Achievements are live and receiving presentation polish. Gear is in its beginning stages, so its current variety and progression depth are intentionally limited. Dynamic map expansion is in development and should not be treated as a live feature.

Browser storage, service workers, strict content blockers, private browsing, or an interrupted network can affect sign-in and installation. The shared server remains authoritative for resources, marches, rewards, battles, ownership, clans, and rankings after a reconnect.

Report an issue

Crownlands uses a public issue tracker for reproducible game and website problems. Search existing reports before opening a new one, describe one issue per report, and exclude sensitive account information.

Open the issue tracker Read the player guide Ask in Discord

For public gameplay discussion and non-sensitive questions, the official Discord is available. For a reproducible defect, the issue tracker keeps technical details attached to one report. Never post passwords, sign-in codes, access tokens, private account identifiers, or another person’s personal information in either place.
